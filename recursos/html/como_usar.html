Primeros pasos

Cómo usar este repositorio

Un único proyecto para todo el módulo, con un tema en cada rama. Aquí tienes cómo clonarlo, traer cada tema nuevo y estudiarlo sin meterte en líos con Git.

1

Qué es este repositorio

En este módulo trabajas siempre con un único proyecto. Cada rama es un tema: al cambiar de rama, el proyecto cambia al código de ese tema, con sus explicaciones en sus apuntes HTML y en los comentarios TODO del código. La rama main es la base del proyecto.

Las ramas se publican a medida que avanzamos. Cuando se publica una nueva, solo tienes que traerla a tu copia.

2

Clonar el repositorio

Solo se hace una vez, al principio del curso.

  1. En la pantalla de bienvenida de Android Studio pulsa Clone Repository (con un proyecto abierto: File → New → Project from Version Control).
  2. Pega la dirección del repositorio y elige la carpeta donde guardarlo.
  3. Espera a que Gradle termine de sincronizar. La primera vez descarga lo necesario y tarda unos minutos. Si te pide instalar una plataforma del SDK, acepta.

Desde la terminal sería:

git clone <dirección del repositorio>
3

Traer un tema nuevo

Cuando se publique una rama nueva:

git fetch git switch UD_2_1_Button
git fetchDescarga la lista de ramas nuevas y sus cambios, sin tocar tus ficheros.
git switch <rama>Cambia tu proyecto a esa rama.
git branch -aMuestra todas las ramas: las tuyas y las del repositorio.
Desde los menús de Android Studio

Menú Git → Fetch. Después, en el selector de ramas de la barra principal (arriba a la izquierda, junto al nombre del proyecto), busca la rama en Remote y elige Checkout.

4

Estudiar una rama

  1. Abre el README.md de la rama: es el índice con el enlace a sus apuntes.
  2. Abre los apuntes HTML del tema en el navegador: botón derecho sobre el fichero → Open In → Browser.
  3. Recorre los comentarios TODO del código con la ventana TODO (View → Tool Windows → TODO): un clic en uno te lleva a su línea.
  4. Ejecuta la aplicación y prueba lo que explican los apuntes.

La guía de Android Studio explica las partes del entorno y del proyecto, y está disponible en todas las ramas.

5

Normas para no tener problemas

No modifiques las ramas del profesor

Si una rama se corrige, la recibirás con git pull. Si has cambiado sus ficheros, se producirán conflictos.

5.1Para experimentar, tu propia rama

Crea una rama tuya a partir del tema. En ella puedes cambiar lo que quieras y hacer tus commits:

git switch -c mio/UD_2_1_Button

5.2Recibir una corrección

git switch UD_2_1_Button git pull

5.3Si Git se niega porque tienes cambios sin guardar

git stashAparta tus cambios para recuperarlos después con git stash pop.
git restore .Descarta tus cambios. No tiene vuelta atrás.

Si algo falla

ProblemaSolución
Gradle sync failedFile → Sync Project with Gradle Files. Si persiste, lee el primer error de la ventana Build.
Falta una plataforma del SDKAcepta instalarla en el aviso, o instálala en Tools → SDK Manager.
Error sobre la versión de JavaSettings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK: elige el JDK que trae Android Studio (jbr).
El emulador no arranca o va muy lentoActiva la virtualización (Intel VT-x o AMD-V) en la BIOS.
